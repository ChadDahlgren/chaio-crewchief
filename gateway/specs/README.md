# Historical build specs

Per-file spec sheets used to bootstrap the original gateway build — an
experiment in having a local model implement each file against a frozen
contract. Kept as a record of that process.

**Not current documentation.** These predate the live codebase's actual
contracts; the numbering gap is a spec for the verify/retry/escalate loop
that was removed entirely (see the root README's "Why not have Crew Chief
verify the work too?"). Don't implement against these — read the code and
the root README instead.
